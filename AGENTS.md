## runtime environment

To set up the run-time environment, do "conda activate ./conda/vmr". 

If ./conda/vmr doesn't exist, run ./create_conda_env.sh

## regression testing

When testing, use the VMR_FILE input of ./VMRs/VMR_MSL40.v1.20250307_test_with_longest.xlsx, as described in the "Quick Start/Test" section of ./README.md

When building the production database, use the same protocol, but use VMR_FILE input of ./VMRs/VMR_MSL41.v1.20260320.xlsx
